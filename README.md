# Metadata Frontend (Low-Code UI)

Фронтенд-часть платформы, предоставляющая визуальный конструктор для управления таблицами и динамический интерфейс для работы с данными (CRUD).

## 🛠 Технологический стек
* **Next.js 16.4.4** (App Router)
* **React 19**
* **TypeScript**
* **Tailwind CSS** (для стилизации)
* **ESLint**

## 🚀 Ключевые возможности
1. **Конструктор таблиц**: Создание и удаление таблиц "на лету".
2. **Конструктор полей**: Создание, редактирование (только разрешенных полей) и удаление колонок с настройкой видимости (в списке / в карточке).
3. **Настройка связей (RELATION)**: Выбор связанной таблицы и поля отображения через удобные выпадающие списки (автокомплит).
4. **Динамический UI**: Формы и таблицы автоматически рендерятся на основе метаданных, полученных от бэкенда.
5. **Модальное окно (Popup)**: Удобное создание и редактирование записей без перезагрузки страницы.
6. **Работа с регистром**: Устойчивость к несовпадению регистра колонок в БД и метаданных.

## ⚙️ Настройка и запуск

### 1. Требования
* Установленный Node.js (версия 18+)
* Запущенный бэкенд (Spring Boot) на порту `8080`
